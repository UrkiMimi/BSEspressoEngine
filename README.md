# BS Espresso Engine
This is an experimental map viewer for Beat Saber V3 maps written in Scratch (PenguinMod). I've been working on this to the point I don't want to lose the files lmao. 

### Currently implemented stuff
- V3 Notes
- V2ToV3 map converter
- NE (Partial)
    - Note Coordinates (Broken)
    - Fake Notes
    - Note PointDef Animations
    - AnimateTrack (Notes only. Parented tracks don't work)
    - Custom NJS
